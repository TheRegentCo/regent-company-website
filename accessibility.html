Accessibility

Website accessibility report.

Review of the public Regent Collection website. Last reviewed: 8 October 2026.

This is a self-assessment made public for transparency. It is not an independent accessibility certification and does not claim full WCAG 2.2 AA conformance.

Scope

This review covers the main public pages on regentcompany.co.uk, including corporate pages, venture pages, legal pages and the venture enquiry form. Private administrative tools are outside this public review.

Accessibility measures in place

  • A skip link lets keyboard users move directly to the main content.
  • Links, buttons and form controls have visible keyboard focus indicators.
  • The mobile navigation exposes its open and closed state with aria-expanded and can be closed with the Escape key.
  • Form fields use visible labels, required fields are identified, and submission status is announced through an ARIA live region.
  • The site uses a single readable sans-serif type system with responsive sizing and line height.
  • Core page colours use dark text on light backgrounds or light text on dark backgrounds. Muted gold is used as an accent, not as the only way to communicate meaning.
  • Main layouts reflow for smaller screens and collapse to one column where needed.
  • Reduced-motion preferences are respected and non-essential scroll animation has been removed.
  • Pages use headings, landmarks and descriptive links where practical.

Checks completed

The website has been reviewed for keyboard navigation, visible focus, responsive reflow, form labelling, heading structure, colour contrast across the main design system, mobile navigation behaviour and obvious content or layout issues that could make pages harder to understand.

Colour contrast

Source-level checks on the current palette measure approximately 17.7:1 for primary charcoal on ivory, 5.2:1 for muted body text on the light background, 4.9:1 for the darker gold accent on the light background and 11.1:1 for the lighter gold accent used on dark backgrounds.

Known limitations and further testing

  • A full independent WCAG 2.2 AA audit has not yet been commissioned.
  • Formal testing across a full screen-reader matrix such as VoiceOver, NVDA and JAWS has not yet been completed.
  • Long legal documents may still benefit from additional structural navigation such as a table of contents.
  • Browser and assistive-technology behaviour can differ, so accessibility testing will continue as the site changes.

Report a problem

If you have difficulty using this website, contact enquiries@regentcompany.co.uk. Please include the page address, what you were trying to do and, if possible, the browser or assistive technology you were using.
